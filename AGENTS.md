# AGENTS

Estas instrucciones rigen para todo el repositorio.

## Estilo de código
- Escribe el código en **TypeScript** usando módulos ES.
- Usa **sangría de 2 espacios**, comillas dobles y finaliza cada sentencia con `;`

- Ubica las clases en `src/class` (nombres en PascalCase) y los tipos compartidos en `src/types`.

## Dependencias
- Instala las dependencias con `npm install` antes de ejecutar o testear cambios.

## Pruebas y ejecución
- Después de cualquier cambio, ejecuta `npm test`. Actualmente no existen pruebas, pero el comando debe correr sin errores para considerar válida la modificación

- Para verificar que la aplicación compila y corre, utiliza `npm run dev`

## Git
- No hagas commit de `node_modules` ni de archivos generados.
- Usa mensajes de commit descriptivos (pueden ser en español o inglés).
